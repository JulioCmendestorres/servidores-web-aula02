Servidor local x servidor remoto

O que é o servidor local?

Usado no processo de desenvolvimento e testes. É acessível apenas no próprio computador ou rede interna.


O que é o servidor remoto?

Utilizado para hospedar aplicações acessíveis pela internet. Está disponível para qualquer usuário autorizado,de qualquer lugar do mundo.


O que é o ambiente de desenvolvimento?

O ambiente de desenvolvimento é utilizado por programadores para construir e testar aplicações localmente, sem afetar os usuários reais.


O que é o ambiente de produção?

O ambiente de produção é onde a aplicação está rodando para os usuários finais, e por isso exige muito mais estabilidade, desempenho e segurança.


Exemplo:

No ambiente de produção utilizo o "localhost" para testar a minha página WEB. Quando vou disponibilizar ela na internet, utilizo o servidor Apache.
